## 🎨 Identity Kit Specifications

- **Heading Font**: Inter (700 Bold) — Modern, clean, technical.
- **Body Font**: Inter (400 Regular, 16px base, 1.6 line height) — High legibility for technical code and case studies.

### 2. Color Palette (Hex Codes)
| Element | Hex Code | Visual Swatch Description | Usage Purpose |
| :--- | :--- | :--- | :--- |
| **Primary Background** | `#0B0F19` | Deep Navy / Near-Black | Main page canvas background |
| **Surface / Card BG** | `#1F2937` | Muted Charcoal | Code blocks, case study cards, and container borders |
| **Primary Text** | `#F3F4F6` | Off-White / Near-White | High-contrast body copy & headings |
| **Muted Text** | `#9CA3AF` | Neutral Slate Gray | Captions, metadata, and dates |
| **Accent Color** | `#3B82F6` | Calm AI Electric Blue | Primary CTA buttons, links, and active badges |
